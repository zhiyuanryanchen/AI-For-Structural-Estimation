# 协作指南 {.unnumbered}

本目录面向第一次参与 GitHub 与 Quarto 图书协作的作者。建议先阅读 GitHub 协作指南，完成一次只修改一小段文字的练习，再阅读 Quarto 写作指南并预览自己的章节。

- [Git 与 GitHub 协作指南](github-collaboration-guide.md)：仓库、分支、提交、同步、Issues 和 Pull Request。
- [Quarto 与 `.qmd` 写作指南](quarto-writing-guide.md)：源文件语法、图表公式、交叉引用、预览和多格式导出。

两份指南的共同原则是“小步、可回退、可审阅”。不要直接编辑 `_book/` 或 `_exports/` 中的生成文件；不要在一个 Pull Request 中同时修改无关章节；遇到冲突、数据权限或模型假设变化时暂停并与合作者确认。

项目仓库：<https://github.com/zhiyuanryanchen/AI-For-Structural-Estimation>，默认分支为 `main`。合作者获得仓库权限并完成 GitHub SSH 配置后，按照 GitHub 协作指南完成第一次分支与 Pull Request 练习。
